# Лабораторна робота №1

## Тема

**Expo для створення найпростішого застосунку React Native. Базові компоненти.**

## Опис проєкту

У межах лабораторної роботи було розроблено мобільний застосунок за допомогою React Native та Expo.

Застосунок складається з трьох основних екранів:

- **Головна** — містить пошук та інформаційні картки з новинами.
- **Галерея** — дозволяє переглядати фотографії у вигляді сітки або одного стовпця.
- **Профіль** — містить поля для введення персональної інформації та налаштування сповіщень.

Для навігації між екранами використано нижню панель навігації Bottom Tabs.

Для оформлення інтерфейсу використано вбудований StyleSheet API та Flexbox.

Для роботи з іконками використано @expo/vector-icons, а для відображення зображень — expo-image.

## Інструкція із запуску

Для запуску проєкту необхідно відкрити термінал у папці проєкту та встановити всі необхідні залежності:

    npm install

Після встановлення залежностей застосунок можна запустити командою:

    npx expo start

Після запуску Expo відкриється панель керування, з якої можна вибрати необхідний спосіб тестування застосунку.

## Основні способи запуску мобільного застосунку

### Expo Go

Expo Go дозволяє запустити розроблений застосунок безпосередньо на фізичному смартфоні.

Після виконання команди `npx expo start` необхідно відсканувати QR-код за допомогою смартфона або відкрити проєкт через застосунок Expo Go.

Цей спосіб призначений для тестування застосунку на реальному мобільному пристрої. Він дозволяє перевірити роботу сенсорного керування, відображення елементів інтерфейсу та адаптацію застосунку до реального екрана смартфона.

### Android Emulator

Застосунок також можна запустити за допомогою Android Emulator.

Після виконання команди `npx expo start` можна вибрати запуск застосунку на Android.

Емулятор дозволяє тестувати застосунок без використання фізичного смартфона. Його перевагою є можливість швидко перевіряти різні розміри екранів та виконувати тестування без підключення реального пристрою.

### Expo Web

Також застосунок можна запустити у веббраузері командою:

    npx expo start --web

Цей спосіб зручний для швидкої перевірки інтерфейсу та внесених змін. Водночас вебверсія може відрізнятися від мобільної версії, оскільки деякі можливості React Native працюють по-різному у браузері та на мобільному пристрої.

## Відмінності під час тестування

Expo Go використовується для перевірки застосунку на реальному смартфоні та дозволяє оцінити його поведінку в умовах реального використання.

Android Emulator призначений для тестування Android-застосунку на комп'ютері. Він зручний під час розробки, оскільки не потребує фізичного смартфона.

Expo Web використовується переважно для швидкої перевірки інтерфейсу у браузері. При цьому необхідно враховувати, що вебверсія не завжди повністю відповідає поведінці мобільного застосунку.

Таким чином, використання декількох способів запуску дозволяє перевірити застосунок у різних середовищах та виявити можливі відмінності у відображенні й поведінці компонентів.

## Висновок

Під час виконання лабораторної роботи було створено мобільний застосунок з використанням React Native та Expo.

Було реалізовано три основні екрани: Головна, Галерея та Профіль. Для навігації між ними використано нижню панель Bottom Tabs.

Під час розробки було використано базові компоненти React Native, StyleSheet, Flexbox, FlatList, Pressable, TextInput та Switch. Для роботи з іконками використано @expo/vector-icons, а для відображення зображень — expo-image.

Також було перевірено основні способи запуску застосунку: через Expo Go на фізичному смартфоні, Android Emulator та Expo Web. Це дозволило ознайомитися з особливостями тестування мобільного застосунку в різних середовищах.
